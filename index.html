Інструменти

Технічний стек

Інструмент під задачу. Більшість проєктів — на чистому JavaScript без збірника; там, де потрібні сервер, база, рендеринг на сервері чи розмова з моделлю, з’являються TypeScript, Next.js, PostgreSQL і Python.

01 Frontend

ES-модулі без збірника там, де вистачає платформи; React і Next.js — де потрібні компоненти й рендеринг на сервері. SVG-рушій із власною камерою, Canvas, редактор Monaco.

Vanilla JS (ES2022)TypeScript React · ViteNext.js 16 SVG · CanvasMonaco · Web Workers

02 Backend & Cloud

Три підходи: Firebase чи Supabase як бекенд без сервера — з правилами доступу замість перевірок на клієнті; або власний сервер на Node.js із базою, коли світ має жити тіком, а не запитами.

Node.js · Express · Socket.IOPostgreSQL · Prisma Firestore + RulesSupabase Edge Functions Auth.js · OAuthPython

03 Симуляції

Подієво-орієнтоване ядро, подвійний запис у головній книзі, макроекономічні моделі, детерміновані генератори даних — і мовні моделі там, де вони пишуть сюжет чи резюме, а код стежить за їхньою відповіддю.

Event-driven coreDouble-entry ledger IFRS / МСФЗGeoJSON Structured Outputs

04 Платформа

PWA з офлайн-кешем, Docker на Fly.io й DigitalOcean, CI у GitHub Actions, тестування сценаріїв через Playwright.

Service WorkersDocker Fly.io · DigitalOceanGitHub Actions Cloudflare WorkersPlaywright
Про мене

Хто це пише

Я розробник із Одеси. Мене цікавлять системи, у яких є справжня внутрішня механіка: економіка, що реагує на рішення гравця, бухгалтерія, яка сходиться до копійки, карта світу, згенерована з реальних географічних даних.

Беру найпростіший інструмент, якого досить. Більшість проєктів написані на чистому JavaScript без збірника — так простіше тримати модель під контролем. Next.js, React і власний сервер з’являються там, де без них не обійтися: у мультиплеєрі, у кабінеті з конфіденційними даними, у грі, що розмовляє з моделлю.

Найбільший — Space Strategy MMO: мультиплеерна космічна стратегія, де всі формули живуть на сервері, а світ іде тіком раз на секунду. Поруч — ОСББ «Успіх-25», яким користується реальний будинок, і сайт із робочим кабінетом для практикуючої психологині. Наступний у черзі — UABankSim, симулятор банку з повноцінною головною книгою.
