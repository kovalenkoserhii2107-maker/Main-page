Інструменти

Технічний стек

Інструмент під задачу. Більшість проєктів — на чистому JavaScript без збірника; там, де потрібні сервер, база, рендеринг на сервері чи розмова з моделлю, з’являються TypeScript, Next.js, PostgreSQL і Python.

01 Frontend

ES-модулі без збірника там, де вистачає платформи; React і Next.js — де потрібні компоненти й рендеринг на сервері. SVG-рушій із власною камерою, Canvas, редактор Monaco.

Vanilla JS (ES2022)TypeScript React · ViteNext.js 16 SVG · CanvasMonaco · Web Workers

02 Backend & Cloud

Firebase чи Supabase відповідають за вхід, дані та правила доступу. Cloudflare Worker об’єднує зовнішні API й серверні AI-запити; власний Node.js із базою підтримує світ, який має жити на тіках.

Node.js · Express · Socket.IOPostgreSQL · Prisma Firestore + RulesSupabase Edge Functions Auth.js · OAuthPython

03 Симуляції

Подієво-орієнтоване ядро, подвійний запис у головній книзі, макроекономічні моделі, детерміновані генератори даних — і мовні моделі там, де вони пишуть сюжет чи резюме, а код стежить за їхньою відповіддю.

Про мене

Хто це пише

Я розробник із Одеси. Мене цікавлять системи, у яких є справжня внутрішня механіка: економіка, що реагує на рішення гравця, бухгалтерія, яка сходиться до копійки, карта світу, згенерована з реальних географічних даних.

Беру найпростіший інструмент, якого досить. JavaScript використовую для симуляторів і мережевих ігор; React та TypeScript — для медіатеки й гри з мовною моделлю, Next.js зі статичним експортом — для лендинга психологині.

Найбільший — «Чумацький Шлях»: світ із серверним тіком, PostgreSQL і спільною біржею. Поруч — ОСББ «Успіх-25», медіатека Umbra, навчальні кампанії CodeQuest і мережева TikTakToe. UABankSim поки описаний як концепція: реалізації ядра й публічного демо ще немає.
