# Main-page

Портфоліо Сергія Коваленка. Статичний сайт без збірки: жодного бандлера,
жодного фреймворку — GitHub Pages роздає файли як є.

🔗 https://kovalenkoserhii2107-maker.github.io/Main-page/

## Структура

```
index.html          головна: герой, проєкти, стек, про мене, контакти
uspih25.html        ОСББ «Успіх-25» — PWA для управління будинком
uabiz.html          UABiz — економічний симулятор
politics.html       Grand Strategy — політичний симулятор
uabank.html         UABankSim — банківський симулятор (у розробці)
404.html            сторінка помилки для GitHub Pages

assets/
  css/main.css      уся дизайн-система; кольори й типографіка — у :root
  js/i18n.js        англійський словник + перемикач мови
  js/app.js         поведінка: анімації, палітра команд, лайтбокс
  screens/*.webp    скріншоти проєктів
  favicon.svg
```

## Як це працює

**Дві мови.** Розмітка написана українською — це те, що бачить відвідувач
навіть із вимкненим JavaScript. `assets/js/i18n.js` містить лише англійські
переклади за ключами `data-i18n` і підміняє вміст на льоту. Вибір мови
зберігається в `localStorage`, за замовчуванням береться з мови браузера.

**Теми немає.** Сайт темний за задумом; кожна сторінка проєкту задає свій
акцентний колір атрибутом `data-accent` на `<html>`.

**Прогресивне покращення.** Без JavaScript сайт залишається повністю
читабельним: анімації появи, палітра команд (⌘K / Ctrl+K), лайтбокс галереї
та підсвічування активного розділу — це надбудова, а не умова роботи.
`prefers-reduced-motion` вимикає рух, включно з фоновою сіткою на canvas.

## Локальний запуск

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

Кроку збірки немає: правите файл — оновлюєте вкладку.

## Додати проєкт

1. Скопіювати будь-яку сторінку проєкту як шаблон, змінити `data-accent`.
2. Покласти скріншоти у `assets/screens/` (webp, ширина 1600 px).
3. Додати картку в `index.html` і запис у масив `ITEMS` в `assets/js/app.js`,
   щоб проєкт з'явився в палітрі команд.
4. Додати англійські рядки в `assets/js/i18n.js`.
