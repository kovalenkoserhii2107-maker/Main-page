# Успіх-25 — презентація для ОСББ

[Завантажити PDF](uspih-25-presentation.pdf) · [Переглянути HTML](slides.html)

10 сторінок українською, формат 16:9 (960 × 540 pt). Для голів правлінь
і бухгалтерів інших ОСББ. Акценти: функціональність, місячний цикл,
автоматизація та запуск під інший будинок. Стиль: великі заголовки,
світлі робочі сторінки, темні акценти, сині й м’ятні кольори, векторні схеми.

## Сценарій

1. Повний цикл вашого ОСББ — титульна сторінка.
2. Три кабінети: мешканець, правління, бухгалтер.
3. Від нарахування внесків до закриття періоду.
4. Банківська звірка та платежі з КЕП голови.
5. Документи, договори, постачальники та зарплата.
6. Подвійний запис, ОСВ і контроль закриття місяця.
7. XML, подача в кабінеті ДПС та квитанції.
8. Збори, звернення, документи й кабінет мешканця.
9. Автоматизація, підтвердження людиною та інфраструктура.
10. Контрольний місяць для іншого ОСББ, QR і контакт розробника.

це дані звіту перевірки в репозиторії, а не кількість робочих користувачів
або операцій ОСББ. Тести самого USPIH-25 під час створення презентації
не запускалися. Робочі рахунки, подача ДПС і production deployment
не перевірялися.

Місячний цикл показано для вже реалізованих безготівкових процесів.
Каса, основні засоби, повна автоматична річна звітність і пряма подача
ДПС ще потребують розвитку. Підпис платежів — у Приват24 для бізнесу,
завантаження/підпис/подача XML — в Електронному кабінеті ДПС.
Автоматизація працює разом із підтвердженнями бухгалтера та голови.
Інтернет, Firebase і банківський API потрібні для фінансових операцій;
кеш PWA підтримує інтерфейс. Для іншого ОСББ потрібні окреме налаштування,
адаптація статуту та облікової політики й перевірка початкових даних.
Рекомендований контрольний місяць — сценарій впровадження, не підтверджений
запуск в іншому ОСББ.

## Зображення й шрифт

- Бухгалтерія: оригінальний знімок menu/390-900.png з наведеного коміту.
- Правління: локальний admin.html?preview=admin, js/admin-preview.js;
  штатні демонстраційні дані, без записів у Firebase.
- Обидва знімки збережено у WebP без втрат. Масштабування та рамка телефону
  задані CSS; текст або дані самих знімків не редагувалися.
- Схема будинку, іконки та схема циклу — векторні елементи презентації.
- Manrope — Google Fonts, SIL Open Font License; ліцензія в assets/OFL.txt.
- QR веде на сторінку проєкту в портфоліо, де є екрани та посилання на код.

## Відтворити PDF

Потрібні Python 3, Chromium і залежності з requirements.txt. У середовищі
підготовки використовувався /usr/bin/chromium.

```bash
python -m pip install -r presentations/uspih-25/requirements.txt
python presentations/uspih-25/render.py --chromium /usr/bin/chromium
```

Редагуйте slides.html і presentation.css, потім повторно запустіть render.py.
Шрифт та зображення локальні; для експорту зовнішні запити не потрібні.
render.py перевіряє кількість сторінок, завантаження шрифту/зображень,
межі тексту й основні перетини та блокує експорт за попереджень.
Для знімків кожного слайда додайте --preview-dir /tmp/uspih25-preview.

Готовий PDF перевірено: 10 сторінок, співвідношення 16:9, виділюваний
український текст, активні посилання, QR декодується з PDF і всі сторінки
переглянуто візуально.
