# Успіх-25 — презентація для ОСББ

[Завантажити PDF](uspih-25-presentation.pdf) · [Переглянути HTML](slides.html)

10 сторінок українською, формат 16:9 (960 × 540 pt), для голів правлінь
і бухгалтерів інших ОСББ. Чотири сторінки присвячено мешканцям із прикладами
поточного інтерфейсу. Збережено повний місячний цикл, автоматизацію,
погодження та сценарій запуску. Стиль: великі заголовки, світлі робочі
сторінки, темні акценти, сині й м’ятні кольори, векторні схеми.

## Сценарій

1. Повний цикл вашого ОСББ — титульна сторінка.
2. Мешканцям: квитанції, PDF, баланс, оплата, історія та лічильники.
3. Мешканцям: фактичний стан світла, час відключення, графік ДТЕК і статистика.
4. Мешканцям: FAQ із пошуком, загальнобудинковий чат, звернення й документи.
5. Мешканцям: доходи, витрати, кошторис, постачальники та первинні документи.
6. Від нарахування внесків до закриття періоду: повний місячний цикл.
7. Банківська звірка, платежі з КЕП голови, документи, договори й зарплата.
8. Подвійний запис, ОСВ, закриття місяця, XML та квитанції ДПС.
9. Автоматизація, підтвердження людиною, управління будинком та інфраструктура.
10. Контрольний місяць для іншого ОСББ, QR і контакт розробника.

Квитанції доступні у кабінеті; автоматична розсилка рахунків поштою
не заявляється. Оплата підтверджується у банку, а баланс оновлюється після
надходження та зіставлення платежу у виписці. Приват24, monobank і QR НБУ
отримують підготовлені реквізити; Portmone — окреме посилання на сервіс.

Факт світла береться зі статусу будинку (Android/MacroDroid + webhook або
ручне оновлення правлінням), графік ДТЕК — із налаштованої черги будинку.
Сервер завантажує графік кожні три години. Час завершення планового
відключення не гарантує фактичне ввімкнення. Історична статистика відображає
збережений журнал, а порівняння план/факт використовує поточний графік.

FAQ містить 39 відповідей у шести групах із посиланнями на Статут
«Успіх-25»; для іншого ОСББ потрібна адаптація. Довідник не заявляється
вичерпною відповіддю на будь-яке можливе питання. Загальний чат показує
авторство квартири й перевірену позначку правління. Фінанси будинку,
розшифровки та вкладення показуються після публікації; приватні баланси
квартир залишаються в персональних кабінетах.

Місячний цикл показано для вже реалізованих безготівкових процесів.
Каса, основні засоби, повна автоматична річна звітність і пряма подача
ДПС ще потребують розвитку. Підпис платежів — у Приват24 для бізнесу,
завантаження/підпис/подача XML — в Електронному кабінеті ДПС.
Автоматизація працює разом із підтвердженнями бухгалтера та голови.
Інтернет, Firebase і банківський API потрібні для фінансових операцій;
кеш PWA підтримує інтерфейс. Для іншого ОСББ потрібні окреме налаштування,
адаптація Статуту та облікової політики й перевірка початкових даних.
Рекомендований контрольний місяць — сценарій впровадження, не підтверджений
запуск в іншому ОСББ.

Тести самого USPIH-25 під час оновлення презентації не запускалися.
Робочі рахунки, подача ДПС і production deployment не перевірялися.

## Зображення й шрифт

- Екрани мешканців знято з поточних index.html, CSS та JS-модулів
  вищезазначеної версії. Баланси, журнал світла, повідомлення, звіт,
  постачальники та реквізити — вигадані демонстраційні дані.
- capture-residents.py замінює Firebase лише в локальному браузері
  через resident-demo.js. Зовнішні запити та всі записи блокуються;
  вихідний код застосунку не змінюється. Знімки підписано у презентації.
- Окремі фрагменти статистики знято з відповідних елементів інтерфейсу;
  у макеті їх масштабує CSS. Зображення збережено у WebP без втрат;
  текст і значення самих знімків не редагувалися.
- Попередні assets/uspih-accounting-mobile.webp та uspih-board.webp
  походять із menu/390-900.png і штатного admin.html?preview=admin.
- Схема будинку, іконки та схема циклу — векторні елементи презентації.
- Manrope — Google Fonts, SIL Open Font License; ліцензія в assets/OFL.txt.
- QR веде на сторінку проєкту в портфоліо, де є екрани та посилання на код.

## Відтворити PDF

Потрібні Python 3, Chromium і залежності з requirements.txt.

```bash
python -m pip install -r presentations/uspih-25/requirements.txt
python presentations/uspih-25/render.py --chromium /usr/bin/chromium
```

Редагуйте slides.html і presentation.css, потім повторно запустіть render.py.
Шрифт та зображення локальні; для експорту зовнішні запити не потрібні.
render.py перевіряє кількість сторінок, завантаження шрифту/зображень,
межі тексту й основні перетини та блокує експорт за попереджень.
Для знімків кожного слайда додайте --preview-dir /tmp/uspih25-preview.

Для повторного отримання екранів мешканців із незміненого checkout:

```bash
python presentations/uspih-25/capture-residents.py /path/to/USPIH-25
```

Готовий PDF перевірено: 10 сторінок, співвідношення 16:9, виділюваний
український текст, активні посилання, QR декодується з PDF і всі сторінки
переглянуто візуально.
