ОСББ «Успіх-25»

Progressive Web App для управління будинком Progressive Web App for Residential Management

Про проект About the Project

Комплексний веб-додаток (PWA) для автоматизації процесів управління об'єднанням співвласників багатоквартирного будинку. Додаток надає окремі інтерфейси для мешканців та правління. Проект дозволяє відмовитися від паперового документообігу та месенджерів на користь єдиної, безпечної екосистеми з юридично значущими інструментами.

A comprehensive web application (PWA) for automating the management processes of a homeowners' association. The app provides separate interfaces for residents and the board. The project allows replacing paper documents and messengers with a single, secure ecosystem featuring legally significant tools.

HTML5 / CSS3 (Apple HIG) Vanilla JavaScript (ES Modules) Firebase (Firestore, Auth, Storage) PWA (Service Workers) Google Cloud Functions

Основний функціонал Core Functionality

  • Захищене голосування: Система опитувань із гарантією "1 квартира = 1 голос" на рівні правил бази даних Firestore, з автоматичним підрахунком кворуму за площею та часткою власності. Secure Voting: Polling system with "1 apartment = 1 vote" guarantee enforced by Firestore database rules, featuring automatic quorum calculation by area and ownership share.
  • Біллінг та Квитанції: Автоматизований імпорт заборгованостей з CSV (створено власний парсер), генерація звітів про витрати ОСББ та інтеграція платіжних реквізитів. Billing & Receipts: Automated debt import from CSV (custom parser built), generation of association expense reports, and payment details integration.
  • Автоматизація ДТЕК (IoT): Інтеграція апаратного датчика (Android + MacroDroid), який передає статус електропостачання в додаток, та Cloud-скрейпер графіків відключень з сайту ДТЕК. DTEK Automation (IoT): Integration of a hardware sensor (Android + MacroDroid) transmitting power status to the app, alongside a Cloud scraper for blackout schedules from the DTEK website.
  • Кастомний генератор Excel: Реалізовано власний генератор файлів .xlsx (ZIP-архів + XML) на чистих Typed Arrays без використання важких сторонніх бібліотек, що дозволяє експортувати реєстри власників на льоту. Custom Excel Generator: Built a native .xlsx file generator (ZIP archive + XML) using raw Typed Arrays without heavy third-party libraries, allowing on-the-fly export of ownership registries.
  • Service Workers & Офлайн: PWA кешує інтерфейс та правила Статуту (FAQ), дозволяючи користуватися додатком навіть без підключення до мережі. Власна реалізація pull-to-refresh жесту. Service Workers & Offline: The PWA caches the UI and association bylaws (FAQ), enabling app usage even without a network connection. Custom implementation of the pull-to-refresh gesture.
